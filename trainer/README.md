# 📞 Тренажер холодних дзвінків

Веб-тренажер, на якому менеджер з продажу відточує чотири навички холодного
дзвінка — перш ніж отримати доступ до реальної бази.

Універсальний: ядро курсу однакове для будь-якої компанії, а все специфічне
приходить з **анкети компанії**. Нова компанія заповнює анкету за годину — і має
свій курс із власними прикладами.

**Етап 1 (готово):** мультикомпанійність, ролі, анкета, курс лекцій, тести.
**Далі:** AI-клієнт → рольові дзвінки через WebRTC → голос → кабінет керівника.
Повний план — у `../TRAINER_PLAN.md`.

## Запуск

```bash
cd trainer
npm install
npm run seed:demo   # дві демо-компанії з користувачами (не обов'язково)
npm start           # http://localhost:3100
```

Потрібен **Node.js 22.5+** — використовується вбудований `node:sqlite`, окремий
сервер БД не потрібен. База — один файл у `data/trainer.db`.

Порт: `PORT=8080 npm start`.

### Облікові записи після `seed:demo`

| Логін | Пароль | Роль |
|---|---|---|
| `owner` | `owner` | Власник продукту — бачить усі компанії |
| `rop.dniprograf` | `test1234` | Керівник Дніпрографа |
| `manager.dniprograf` | `test1234` | Менеджер Дніпрографа |
| `rop.smartecopack` | `test1234` | Керівник Смартекопаку |
| `manager.smartecopack` | `test1234` | Менеджер Смартекопаку |

Пароль `owner` змініть одразу після першого входу.

## Як це влаштовано

### Три ролі

| Роль | Що може |
|---|---|
| `owner` | Створює компанії, перемикається між ними. Не прив'язаний до жодної |
| `admin` | Заповнює анкету своєї компанії, заводить менеджерів, бачить звіти |
| `manager` | Вчиться й тренується |

**Мультикомпанійність.** `admin` і `manager` назавжди прив'язані до своєї компанії —
жоден параметр запиту цього не змінює. Перемикатися може лише `owner`. Це єдине
місце (`src/tenancy.js`), де вирішується, чиї дані бачить користувач, і воно
покрите тестами: підміна cookie компанії не дає доступу до чужих даних.

### Анкета компанії

Сім екранів (`src/profile.js`): що продаємо · кому · хто вирішує · переваги ·
ціна · заперечення · що вважається успіхом дзвінка.

З відповідей збирається контекст, який підставляється в лекції через токени
`{{company}}`, `{{product1}}`, `{{obj1}}`, `{{success}}` тощо. Незаповнене поле
замінюється нейтральною заглушкою — курс читабельний ще до заповнення анкети.

Правила написання контенту й повний перелік токенів — `content/README.md`.
Головне: **токен завжди стоїть у називному відмінку** (українська відмінює,
підстановка — ні).

### Курс і тести

Лекції — це дані (`content/lectures/*.js`), а не шаблони: структуровані секції,
які рендеряться однаково. Додати лекцію — це додати файл і рядок у `content/index.js`.

Після кожної лекції тест: 6 питань із банку на 10+, порядок питань і варіантів
перемішується. Прохідний бал 80%. Наступна лекція відкривається лише після
складеного тесту.

Два типи питань:
- **закриті** — рахує код, миттєво, з поясненням до кожного варіанта;
- **вправа «перепиши фразу»** — не впливає на бал; оцінює Claude за критеріями
  лекції. Без `ANTHROPIC_API_KEY` відповідь просто зберігається й потрапляє
  керівнику в розділ «Вправи» — тренажер працює далі.

### AI-перевірка вправ (не обов'язкова)

```bash
export ANTHROPIC_API_KEY=...   # без ключа все працює, крім автоперевірки вправ
```

Модель і промпт — `src/ai.js`. Оцінка йде строго за критеріями питання; вигадувати
факти про продукт компанії моделі заборонено.

## Структура

```
server.js              точка входу, вхід/вихід, перемикання компанії
src/
  db.js                схема (tenant_id у кожній таблиці), створення компаній і людей
  tenancy.js           хто чиї дані бачить — єдине місце
  auth.js              сесії, паролі
  profile.js           анкета компанії: екрани, валідація, контекст для лекцій
  course.js            прогрес, послідовність, підстановка даних у лекції
  quiz.js              добір питань і перевірка
  ai.js                перевірка відкритих відповідей через Claude
  format.js            екранування, {{підстановка}}, детермінований генератор
  routes/              dashboard, profile, course, admin
content/
  index.js             порядок лекцій
  lectures/            лекції як дані
  README.md            правила написання контенту
views/                 EJS
test/                  node --test
```

## Тести

```bash
npm test
```

35 тестів. Найважливіші — `tenancy.test.js` (дані компаній не перетинаються) та
`app.test.js` (наскрізний прохід: вхід → лекція → тест → наступна лекція, разом із
перевіркою, що підміна cookie не відкриває чужу компанію).

## Розгортання

Застосунок навмисне простий: один процес, один файл бази, жодної збірки. За
зворотним проксі увімкніть `TRUST_PROXY=1` і `COOKIE_SECURE=1` після налаштування
HTTPS.
