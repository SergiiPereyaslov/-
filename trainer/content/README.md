# Контент курсу

Ядро курсу — universal. Усе, що специфічне для компанії, приходить із анкети
через токени `{{token}}`.

## Доступні токени

| Токен | Звідки | Приклад |
|---|---|---|
| `{{company}}` | Назва компанії | Дніпрограф |
| `{{product1}}`, `{{product2}}`, `{{products}}` | Що продаємо | Візитки та листівки |
| `{{portrait1}}`, `{{portrait2}}` | Портрети клієнта | Рекламна агенція — акаунт-менеджер |
| `{{decider}}`, `{{gatekeeper}}`, `{{gatekeeperPhrase}}` | Хто вирішує / хто бере трубку | |
| `{{adv1}}`, `{{adv2}}`, `{{competitor}}` | Переваги | Друк за два дні |
| `{{priceAnchor}}` | Ціновий орієнтир | |
| `{{obj1}}`, `{{obj2}}` | Заперечення | Дорого, беремо дешевше |
| `{{success}}`, `{{nextStepPhrase}}` | Мета дзвінка | домовилися про зустріч |

Незаповнене поле замінюється нейтральною заглушкою — курс читабельний ще до
заповнення анкети.

## Головне правило: токен стоїть у називному відмінку

Українська відмінює, а підстановка — ні. «Дзвінок у {{company}}» перетвориться на
«дзвінок у Дніпрограф» — і це видно всім. Тому токен ставимо туди, де потрібен
називний відмінок: після двокрапки, тире або на початку речення.

```
Погано:  Телефоную щодо {{product1}}        → «щодо Візитки та листівки»
Добре:   Телефоную у справі: {{product1}}.  → «у справі: Візитки та листівки»

Погано:  Успішний дзвінок у {{company}}     → «у Дніпрограф»
Добре:   {{company}} — успішний дзвінок…    → «Дніпрограф — успішний дзвінок…»
```

Перевірка автоматизована: тест `course.test.js` падає, якщо в готовому тексті
лишився неопрацьований `{{token}}`. Відмінки перевіряє людина під час рев'ю.

## Типи секцій

`p` · `h` · `note` · `list` · `steps` · `company` · `formula` · `pair` (погано/добре)
· `funnel` · `levels` · `chain` · `exercise`

У текстах працює `**жирний**`. HTML екранується — вставити розмітку з тексту лекції
не вийде.

## Типи питань

- `single` — закрите питання. Рівно один варіант із `ok: true`, у кожного варіанта
  обов'язкове пояснення `why` (його бачать і при правильній, і при хибній відповіді).
- `rewrite` — вправа «перепиши фразу». Не впливає на бал за тест; оцінюється AI за
  критеріями `criteria`, `reference` — орієнтир, а не єдина правильна відповідь.

У банку має бути щонайменше 10 закритих питань на лекцію: тест бере 6 випадкових.
