# Етап 3. Дизайн-система

Реалізація — Tailwind CSS v4 (CSS-first, `@theme` у `web/src/app/globals.css`).
Документ описує рішення; джерело істини — код.

## 1. Фірмова палітра

Кольори зняті з чинного сайту smartecopack.com: темно-зелений топ-бар,
м'ятний акцент із фотографій, тепле молочне тло й сірий (не чорний) текст.

> Значення визначені зі скріншотів, а не з брендбука. Перед запуском їх
> треба звірити з оригінальними — різниця в кілька відсотків непомітна на
> око, але видна поруч із друкованими матеріалами.

| Роль | Токен | Light | Dark |
|---|---|---|---|
| Темно-зелений: топ-бар, підвал | `--deep` | `#2F5C23` | `#24401C` |
| Текст на темно-зеленому | `--on-deep` | `#F1F3EA` | `#ECEEE7` |
| Дія (кнопки, посилання) | `--primary` | `#4E9E6A` | `#6FBF8C` |
| Дія: наведення | `--primary-hover` | `#3F8757` | `#82CC9C` |
| М'ятний із фотографій | `--mint` | `#86C9A4` | `#86C9A4` |
| М'ятна підкладка | `--accent-soft` | `#E3F0E8` | `#22301F` |
| Акцент (знижка, термін) | `--accent` | `#2F5C23` | `#86C9A4` |
| Основний текст | `--ink` | `#46493F` | `#ECEEE7` |
| Приглушений текст | `--muted` | `#6E7268` | `#A5AA9F` |
| Тло сторінки | `--bg` | `#F4F4EF` | `#171A14` |
| Тло картки | `--surface` | `#FFFFFF` | `#1F231C` |
| Секційне тло | `--kraft` | `#EDEDE5` | `#262A22` |
| Рамка | `--border` | `#E1E1D7` | `#333829` |

**Помаранчевого в бренді немає.** Тому «акцент» для знижок і термінів — це
темно-зелений на м'ятній підкладці, а не окремий колір. Це навмисне
обмеження: додати помаранчевий було б простіше, але сайт перестав би
виглядати як продовження фірмового стилю.

## 2. Типографіка

Фірмовий шрифт бренду — **Comfortaa**: геометричний гротеск з округлими
закінченнями. Він задає впізнаваність, тому використовується скрізь, де
текст читається з одного погляду.

| Роль | Шрифт | Розмір | Насиченість |
|---|---|---|---|
| H1 | Comfortaa | 32 / 44 px (моб/деск) | 700 |
| H2 | Comfortaa | 24 / 32 | 700 |
| H3 | Comfortaa | 19 / 22 | 600 |
| Навігація, кнопки | Comfortaa | 15 | 600 |
| Ціна | Comfortaa | 24 / 28 | 700, табличні цифри |
| Тіло, довгі тексти | Comfortaa | 16 | 300–400 |
| Дрібне, ТТХ, артикул | Comfortaa | 13 | 400, `tabular-nums` |

**Comfortaa всюди — за вашим рішенням.** У попередній версії довгі тексти були
набрані Inter: суцільний абзац на 2000 знаків у Comfortaa читається важче,
бо округлі форми зменшують різницю між літерами. Ви обрали повну відповідність
бренду, і Inter прибрано з сайту повністю — лишився один шрифт на всі ролі.

Що зроблено, щоб компенсувати: у шрифт додано нарис **300** (Light) — саме він
знімає відчуття «жирності» на довгих абзацах, де 400 виглядає надто щільно.
Якщо на реальних SEO-текстах читабельність усе-таки муляє, повернення Inter для
тіла — одна зміна `--font-sans` у `globals.css`, решта не зачіпається.

Comfortaa підключений через `next/font` із кириличною підмножиною й
самохоститься: зовнішніх запитів до Google на сторінці немає.

На відміну від попередньої версії, у заголовках **немає від'ємного
трекінгу**: Comfortaa геометричний і широкий, стиснення псує його ритм.

Кнопки — з повним заокругленням (`border-radius: 999px`), як на чинному
сайті.

## 3. Сітка та простір

- Контейнер: 1280 px, бічні відступи 16 (моб) / 24 (планшет) / 32 (деск)
- Сітка товарів: 2 колонки (моб) → 3 (768) → 4 (1280)
- Крок відступів: 4 px. Використовувані значення: 4, 8, 12, 16, 24, 32, 48, 64, 96
- Вертикальний ритм секцій: 48 (моб) / 80 (деск)

## 4. Радіуси, тіні, межі

| Токен | Значення | Де |
|---|---|---|
| `--radius-sm` | 8px | інпути, чіпи |
| `--radius-md` | 12px | картки, кнопки |
| `--radius-lg` | 20px | модалки, hero-блоки |
| `--shadow-card` | `0 1px 2px rgb(0 0 0 / .04), 0 4px 12px rgb(0 0 0 / .05)` | картка товару при наведенні |

Тіні мінімальні. Розділення — рамкою `--color-border`, не тінню: на крафтовому
фоні тіні виглядають брудно.

## 6. Фокус і доступність

- `:focus-visible` — обведення 2 px `--color-primary` з відступом 2 px.
  Ніколи не `outline: none` без заміни.
- Мінімальна площа дотику 44×44 px.
- Контраст перевіряється для обох тем; `--color-muted` на `--color-bg`
  дає 5.2:1 у світлій і 6.1:1 у темній.
- Анімації вимикаються за `prefers-reduced-motion`.

## 7. Зображення

- Формати AVIF → WebP → JPEG через `next/image`
- Співвідношення сторін товару 1:1, фон нейтральний
- `sizes` прописується для кожної сітки, щоб не тягнути 1200 px у мобільну картку
- Перше фото товару в категорії — `priority` тільки для першого екрана
- Обов'язковий `alt` за шаблоном: «{назва} {об'єм} {колір} — SmartEcoPack»

## 8. Бюджет продуктивності

| Метрика | Ціль | Факт (2026-09-07) |
|---|---|---|
| LCP | < 2.0 с | міряти на бойовому хостингу |
| CLS | < 0.05 | міряти на бойовому хостингу |
| INP | < 200 мс | міряти на бойовому хостингу |
| JS на сторінці категорії | < 120 KB gzip | **~180 KB — не виконано** |
| CSS | — | 7.5 KB gzip |
| HTML сторінки категорії | — | 17.7 KB gzip |
| Шрифти | 2 сімейства × 2 накреслення | 4 файли woff2 (latin + cyrillic) |

**Про невиконаний бюджет JS.** 120 KB був нереалістичною цілью для
React-застосунку: ~175 KB з виміряних 180 — це базовий рантайм React 19 і
Next 16, власний код сторінки додає одиниці кілобайтів. Скоротити можна лише
прибравши інтерактивність із картки товару в сітці (степер і «в кошик»),
що підніме кількість кліків до замовлення — не рекомендую.

Пом'якшує ситуацію те, що всі 386 сторінок віддаються статичним HTML: контент
видно до гідратації, тому LCP від обсягу JS практично не залежить. Це і є
основний важіль швидкості та головна причина вибору Next.js замість готової
платформи.
