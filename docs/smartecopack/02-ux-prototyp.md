# Етап 2. UX-прототип

Головний критерій із ТЗ — **максимальна простота навігації**. Нижче кожне
рішення підпорядковане цьому, а не «красі».

## 1. Глобальний каркас

### Шапка (2 рівні, липкий 2-й на скролі)

```
┌───────────────────────────────────────────────────────────┐
│ Дніпро, пр. О. Поля 82г · Пн–Пт 9–18   [UA|RU]  0 50 280…│  топ-бар
├───────────────────────────────────────────────────────────┤
│ [SmartEcoPack]  [🔍 пошук по каталогу        ]  [☎] [🛒 3]│  головний
├───────────────────────────────────────────────────────────┤
│ Каталог ▾ · Брендування · Доставка й оплата · Блог · Про нас · Контакти │
└───────────────────────────────────────────────────────────┘
```

- «Каталог ▾» розкриває мега-меню на 5 колонок = 5 груп, у кожній 3–9 категорій.
  Одне відкриття — уся структура сайту перед очима. Це і є «просто».
- Пошук — не іконка, а поле. Аудиторія шукає артикулом і розміром, поле має
  бути видимим одразу.
- Кошик показує кількість позицій і суму.

**Мобільна шапка:** логотип · пошук · кошик; меню-бургер відкриває той самий
список 5 груп з розкриттям в акордеон. Телефон і Telegram — липкою кнопкою внизу.

### Підвал

4 колонки: Каталог (5 груп) · Компанія · Клієнтам (доставка, оплата,
брендування, оферта) · Контакти з картою проїзду. Нижче — реквізити ТОВ і рік.

## 2. Головна

Порядок блоків = порядок меседжів «швидкість → брендування → асортимент → еко»:

1. **Hero.** H1 «Паперова упаковка для їжі навинос у Дніпрі».
   Підзаголовок з головною перевагою: власний склад, доставка за 24 години,
   безкоштовно по місту. Дві кнопки: «Перейти в каталог» / «Отримати прайс».
2. **Смуга переваг** (4 плитки з цифрами): 24 год доставка · безкоштовно по
   Дніпру · від 1 пачки · друк логотипу від 100 шт.
3. **5 груп каталогу** — великі картки з фото й переліком категорій усередині.
   Головний навігаційний вузол сторінки.
4. **Хіти продажів** — 8 товарів з ціною й кнопкою «В кошик».
5. **Брендування** — банер із калькулятором-тизером: «Стакани з вашим логотипом
   від 100 шт». Веде на `/brenduvannya/`.
6. **Як ми працюємо** — 4 кроки: заявка → прорахунок менеджером → узгодження →
   доставка за 24 год.
7. **Для кого** — 4 сегменти (кав'ярня, фастфуд, доставка, кондитерська) з
   посиланнями на релевантні групи.
8. **FAQ** — 6 питань (мінімальна партія, опт від якого обсягу, терміни
   брендування, оплата, доставка по Україні, сертифікати). Дає FAQPage-розмітку.
9. **Контактний блок** — форма «Отримати прайс» + карта + месенджери.

## 3. Сторінка групи `/catalog/{group}/`

H1 = назва групи. Далі: 2–3 абзаци вступного тексту (SEO + орієнтація),
плитка категорій із фото та лічильником товарів, під нею — топ-12 товарів
групи, унизу розгорнутий SEO-текст і FAQ групи.

## 4. Сторінка категорії `/catalog/{category}/`

```
Головна / Для напоїв / Стакани паперові
H1: Паперові стакани для кави
[короткий вступ 2 речення]

┌ фільтри (ліва колонка, десктоп) ┬ сітка товарів ─────────┐
│ Об'єм    ☐110 ☐175 ☐250 ☐340   │ [сортування ▾] 24 товари│
│ Колір    ☐крафт ☐білі ☐чорні   │ ┌────┐┌────┐┌────┐      │
│ Матеріал ☐1РЕ ☐2РЕ              │ │карт││карт││карт│      │
│ В пачці  ☐50 ☐100               │ └────┘└────┘└────┘      │
│ Ціна     [—-●—-]                │                         │
│ ☐ Можна з логотипом             │ [Показати ще]           │
└─────────────────────────────────┴─────────────────────────┘

[швидкі посилання на фасети: 175 мл · 250 мл · 340 мл · крафт]
[SEO-текст категорії + FAQ]
```

- На мобільному фільтри — кнопка «Фільтри (2)», що відкриває шторку знизу.
- Обрані фільтри — чіпи над сіткою з хрестиком, «Скинути все».
- Пагінація: «Показати ще» + класична нумерація внизу для індексації.

### Картка товару в сітці

Фото · назва · ключовий параметр (об'єм/розмір) · «100 шт/пач» ·
**ціна за пачку** великим, ціна за штуку сірим · бейдж «опт від 10 пач −12%» ·
кнопка «В кошик» + степер кількості одразу в сітці (менше кліків до замовлення).

## 5. Картка товару `/product/{slug}/`

```
Хлібні крихти
┌ галерея ─────────┬ панель замовлення ──────────────────┐
│                  │ H1: Стакан паперовий 340 мл, крафт  │
│  [фото 1..4]     │ Артикул SEP-ST-340-KR · ✔ у наявності│
│                  │ ─────────────────────────────────    │
│                  │ Роздріб   4,20 грн/шт · 420 грн/пач │
│                  │ Опт від 10 пач.  3,70 грн/шт  −12%  │
│                  │ [ − 1 + ] пачок      [ У КОШИК ]     │
│                  │ [Отримати прайс] [Написати в Telegram]│
│                  │ 🚚 Дніпро — завтра, безкоштовно      │
│                  │ 🏷 Друк логотипу від 100 шт          │
└──────────────────┴──────────────────────────────────────┘
[Характеристики] [Опис] [Доставка й оплата]
── Пасують кришки (Ø80 мм) ────  ← крос-продаж за таблицею сумісності

```

Ключове: **обидві ціни видно без реєстрації**. Це головна відмінність від
конкурентів, які ховають опт за «зателефонуйте».

## 6. Кошик-заявка

Три екрани, без реєстрації:

1. `/koshyk/` — таблиця позицій, зміна кількості, автоматичний перерахунок
   на оптову ціну при перетині порогу з підказкою «додайте ще 2 пачки — ціна
   впаде на 12%».
2. `/oformlennya/` — ім'я, телефон (обов'язкові), решта опційно: заклад,
   спосіб доставки (самовивіз / Дніпро / Нова пошта), коментар. Тип клієнта
   ФОП/ТОВ → поле для реквізитів на рахунок.
3. `/dyakuyemo/` — номер заявки, що далі, контакт менеджера.

Оплати онлайн немає — менеджер підтверджує наявність і виставляє рахунок.

## 7. Брендування `/brenduvannya/`

Головний блок — **калькулятор**: тип виробу → тираж → кількість кольорів →
орієнтовна ціна за штуку та строк. Це прямо знімає ключове заперечення
(«скільки коштує з логотипом і від якого тиражу»), яке конкуренти залишають
без відповіді.

Далі: приклади робіт, 4 кроки процесу, вимоги до макета (з посиланням на
шаблон), FAQ, форма з завантаженням макета.

## 8. Пошук

Живі підказки з 3-го символу, три групи результатів: товари (з фото й ціною),
категорії, статті. Пошук по назві, артикулу й числовому розміру — запит «340»
має знаходити всі стакани 340 мл.

## 9. Наскрізні елементи

| Елемент | Поведінка |
|---|---|
| Липка панель контактів | праворуч на десктопі, знизу на мобільному: телефон, Telegram, Viber |
| Хлібні крихти | на всіх сторінках крім головної, з розміткою |
| «Отримати прайс» | модальне вікно з полем телефону, доступне з будь-якої сторінки |
| Порожні стани | «Нічого не знайдено» з кнопкою скидання фільтрів і топ-категоріями |
| Помилки форм | під полем, українською, без червоних рамок на незаповнених |

## 10. Правила доступності

Контраст тексту ≥ 4.5:1, фокус видимий на всіх інтерактивних елементах,
всі поля з `<label>`, зображення з `alt`, навігація клавіатурою, шторка
фільтрів із пасткою фокуса й закриттям на Esc.
