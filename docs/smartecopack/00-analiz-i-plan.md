### 1.4 Виявлені SEO-проблеми

1. **Непослідовні URL.** `/catalog/Lanch-box` — з великої літери (ризик дублів
   на рівні регістру). Змішана транслітерація: `trubochki`, `krishki`,
   `stakani` — російська транслітерація при українському контенті.
2. **URL не відповідає змісту.** Категорія «Тарілки та соусники» живе на
   `/catalog/tarilka-pryamokutna` — вузький URL під широку категорію.
3. **Ризик дублів пагінації.** Існує `/catalog/upakovka-dlya-fast-fudu/page-all`
   поряд зі звичайною пагінацією — без жорсткого canonical це дублі.
4. **Слід міграції без редиректів.** Стаття з українським заголовком лежить на
   `/news/bumazhnaya-upakovka-dlya-edy-navynos-ot-smartekopak` — російський slug.
   Схоже, рос. версію перекладали «поверх» без роботи з URL.
5. **Перевантажені title товарів.** Приклад: «Салатниця 550 мл KRAFT / Ø 142 мм,
   1РЕ (50/400) оптом і в роздріб від виробника з доставкою по Україні» —
   ~110 символів, у видачі обрізається, ключ «оптом» іде за межі видимого.
6. **`/all-products`** — потенційно «тонка» сторінка-дубль каталогу.
7. **Дві мовні версії** без підтвердженої hreflang-стратегії (перевірити).
8. **Плоска навігація з 17 категорій** — користувач не має проміжного рівня
   групування, а сайт не має посадкових сторінок під широкі запити.

## 2. Ніша та ринок

Сегмент: **одноразова паперова/крафтова упаковка для HoReCa**, B2B з домішкою B2C.

Драйвери попиту:
- зростання takeaway та сервісів доставки, dark kitchens;
- законодавче обмеження пластику в Україні → перехід на папір/крафт;
- упаковка з логотипом як дешевий маркетинговий канал для закладу;
- відбудова/релокація закладів — постійний потік нових точок.

Сезонність:
- **пік 1:** квітень–серпень — холодні напої, стакани, трубочки, пікніки;
- **пік 2:** листопад–грудень — свята, подарункова та кондитерська упаковка;
- **спад:** січень–лютий.

Конкуренція: висока по Україні, помірна локально в Дніпрі. Домінують київські
гравці з великим доменним авторитетом.

**Ключовий інсайт для UX і SEO:** аудиторія шукає не «упаковку», а
**конкретний розмір**: «стакан 340 мл двошаровий», «крафт пакет з ручками
32×20», «салатник 500 мл з кришкою», «контейнер алюмінієвий 960 мл».
Тому фільтри за об'ємом / діаметром / матеріалом / кількістю в пачці —
одночасно і навігація, і фабрика посадкових сторінок.

**Ключове заперечення:** «а скільки коштує з моїм логотипом і від якого тиражу».
Відповідь має бути на сайті, а не «залиште заявку».

## 5. Концепція нового сайту

### 5.1 Навігація (вимога «максимально просто»)

Верхнє меню — **6 пунктів**: Каталог · Брендування · Доставка й оплата ·
Блог · Про нас · Контакти.

Каталог перебудовується з 17 плоских категорій у **5 груп**:

1. **Для напоїв** — стакани (одношарові, двошарові, гофровані), кришки,
   термочохли, тримачі, трубочки паперові/полімерні, мішалки
2. **Їжа навинос** — ланч-бокси, салатники, супниці, алюмінієві контейнери,
   тарілки та соусники
3. **Фастфуд** — бургер-бокси, картопля фрі, хот-дог, снек-упаковка
4. **Пакети** — з ручками, без ручок, саше
5. **Супутні товари** — серветки, рукавички, стіки цукру, чайні пакети

Правило: **не більше 3 кліків** від головної до товару.
Головна → група → категорія → товар.

### 5.2 Наскрізні елементи

- Фільтри: об'єм, діаметр, матеріал, колір, «з логотипом», кількість у пачці, ціна
- Пошук з підказками по назві, розміру та артикулу
- Дві ціни в картці: роздріб і опт (від N упаковок) — видимі без реєстрації
- Швидке замовлення в один екран: кошик → телефон → підтвердження менеджером
- Липкий блок «Замовити дзвінок / Telegram / Viber»
- Калькулятор брендування: тираж × тип стакана → орієнтовна ціна за штуку

### 5.3 Шаблони сторінок (8)

Головна · Група каталогу · Категорія · Картка товару · Брендування ·
Доставка й оплата · Блог + стаття · Контакти. Плюс службові: кошик,
оформлення, подяка, 404, політика конфіденційності.

## 6. Технічний стек

**Ухвалено: Next.js 15 (App Router) + TypeScript + Tailwind CSS +
PostgreSQL (Prisma) + деплой на власний VPS.**

Чому:
- SSG/ISR для каталогу → миттєве завантаження й ідеальні Core Web Vitals,
  що прямо впливає на ранжування;
- повний контроль над URL, canonical, hreflang, розміткою — те, чого не дають
  Хорошоп/Prom;
- статичний каталог витримує будь-який сплеск трафіку на дешевому хостингу;
- легко нарощувати фільтрові посадкові сторінки.

Розглянуті й відхилені альтернативи:
- **Хорошоп / Prom** — швидкий старт, але стеля по SEO й дизайну, оренда назавжди;
- **WordPress + WooCommerce** — дешева підтримка, гірша швидкість, більше вразливостей.

## 7. SEO-план

### 7.1 Семантика
- Збір ~600–900 запитів (комерційні + розмірні + інфо)
- Кластеризація: 5 груп → 20–25 категорій → 30–50 фільтрових посадкових
  («стакани 250 мл», «стакани 340 мл», «крафт пакети з ручками»)
- Окремі кластери: «оптом», «з логотипом», «Дніпро/Київ/Харків»

### 7.2 Технічне SEO
- Чисті URL: `/catalog/stakany-paperovi/`, lowercase, українська транслітерація,
  без `/page-all`
- Canonical на всіх пагінаціях і фільтрах; індексуємо тільки відібрані фільтри
- `hreflang` uk ↔ ru + `x-default`
- **Мапа 301-редиректів зі 100% старих URL** — критичний пункт міграції
- XML-sitemap, розбитий на catalog / products / blog / pages; robots.txt
- Schema.org: Organization, LocalBusiness, BreadcrumbList, Product + Offer +
  AggregateRating, FAQPage, Article
- Швидкість: WebP/AVIF, lazy-load, preload шрифтів, LCP < 2.5 с, CLS < 0.1
- Хлібні крихти на всіх рівнях

### 7.3 Контент
- Унікальні SEO-тексти для 20–25 категорій (1500–2500 знаків, під кластер)
- Розширені описи товарів: розмір, щільність, к-сть у пачці, сумісні кришки,
  «підходить для…»
- Перенесення блогу з 301 + контент-план 4 статті/міс
- FAQ на категоріях і в картці (працює на FAQPage-розмітку)

### 7.4 Локальне SEO
- Google Business Profile (Дніпро, шоурум), LocalBusiness schema, NAP-консистентність
- Посадкові «упаковка для їжі Дніпро / Київ / Харків / Запоріжжя»

### 7.5 Аналітика
GA4 + Google Search Console + Bing Webmaster, події: заявка, дзвінок,
клік у Telegram/Viber, додавання в кошик, оформлення. Валідація розмітки.

## 9. Оцінка часу

**Обсяг:** ≈ 287 людино-годин (з урахуванням двомовності).

| Сценарій | Термін |
|---|---|
| Класична команда (дизайнер + фронт + бек + SEO), паралельно | 7–8 тижнів |
| Один розробник фултайм | 8–9 тижнів |
| **Мій темп (агент + підагенти, паралельні етапи)** | **14–16 робочих сесій ≈ 3 тижні календарно** |

Мій критичний шлях — **не код, а контент від вас**: вивантаження товарів,
фотографії, актуальний прайс і краул старого сайту. Технічну частину (етапи
2–6, 8) я закриваю швидко; етапи 0, 1, 7 залежать від швидкості ваших відповідей.

**Реалістичний графік по тижнях:**

- **Тиждень 1:** етапи 0–3 — ТЗ, семантика, прототип, дизайн-система
- **Тиждень 2:** етапи 4–6 — фронтенд, каталог, фільтри, адмінка
- **Тиждень 3:** етапи 7–11 — контент, двомовність, SEO, QA, запуск + моніторинг
