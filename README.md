# 🧾 Веб-система виставлення рахунків

Простий веб-інтерфейс для виставлення рахунків замість Excel. Створений для
**ТОВ без ПДВ**, розрахований на **кількох менеджерів** зі спільною базою.
Інтерфейс і рахунки — українською.

## Можливості

- **Виставлення рахунків через форму** з динамічними позиціями та живим підрахунком суми.
- **Стандартний український «Рахунок на оплату»** — готовий до друку або збереження в PDF.
- **Сума прописом** українською з правильними родовими формами (одна гривня, дві гривні, двадцять одна тисяча…).
- **База покупців** — вводите реквізити один раз, далі обираєте зі списку.
- **Каталог товарів і послуг** — швидке додавання позицій у рахунок у два кліки.
- **Історія рахунків** з пошуком, фільтрами та статусами оплати (оплачено / не оплачено).
- **Автоматична нумерація** рахунків (із префіксом за бажанням, окрема нумерація по роках).
- **Кілька користувачів** із логіном; видно, який менеджер створив рахунок.
- **Копіювання рахунку** — швидко виставити схожий рахунок на основі наявного.

## Вимоги

- **Node.js версії 22.5 або новішої** (використовується вбудований модуль `node:sqlite`).
  Перевірити версію: `node --version`.
- База даних — файл SQLite, окремий сервер БД не потрібен.

## Встановлення та запуск

```bash
# 1. Встановити залежності
npm install

# 2. Запустити сервер
npm start
```

Після запуску відкрийте у браузері: **http://localhost:3000**

За замовчуванням при першому запуску створюється адміністратор:

- **Логін:** `admin`
- **Пароль:** `admin`

> ⚠️ Одразу після входу змініть пароль (кнопка «Пароль» угорі справа) і заповніть
> реквізити вашого ТОВ у розділі **«Реквізити»** — без них рахунки виставити не можна.

### Порт

За замовчуванням `3000`. Змінити можна через змінну оточення:

```bash
PORT=8080 npm start
```

## Перші кроки

1. Увійдіть як `admin` / `admin` і **змініть пароль**.
2. Заповніть **«Реквізити»** — назву ТОВ, ЄДРПОУ, IBAN, банк, ПІБ керівника.
3. У розділі **«Користувачі»** додайте менеджерів (кожному — свій логін і пароль).
4. Додайте **покупців** та **товари/послуги** (за бажанням — база наповнюється й у процесі роботи).
5. Натисніть **«Новий рахунок»**, оберіть покупця, додайте позиції — і **«Друк / PDF»**.

## Розгортання для кількох менеджерів

Щоб менеджери працювали одночасно через браузер зі спільною базою, застосунок
має бути запущений на одному спільному комп'ютері або сервері, доступному в мережі:

- **У локальній мережі офісу:** запустіть `npm start` на робочому комп'ютері (сервері),
  дізнайтеся його IP-адресу (напр. `192.168.1.50`) — менеджери заходять за адресою
  `http://192.168.1.50:3000`.
- **На хостингу/VPS:** розгорніть так само; рекомендовано за зворотним проксі (nginx)
  з HTTPS. Для автозапуску зручно використати `systemd` або `pm2`.

Дані зберігаються у файлі `data/invoices.db`. Одночасну роботу забезпечує режим WAL.

## Резервне копіювання

Уся інформація — в одному каталозі **`data/`**. Достатньо регулярно копіювати його
(файли `invoices.db`, `invoices.db-wal`, `invoices.db-shm`) у надійне місце.
Відновлення — повернути ці файли на місце.

## Тести

```bash
npm test
```

Перевіряються найважливіші розрахунки: сума прописом, форматування грошей і дат,
розбір позицій рахунку.

## Структура проєкту

```
server.js               # запуск, автентифікація, дашборд, підключення маршрутів
src/
  db.js                 # база даних (node:sqlite), схема, транзакції
  auth.js               # логін, сесії, права доступу
  format.js             # сума прописом, формат грошей і дат (українською)
  invoiceHelpers.js     # нумерація, розбір і підрахунок позицій
  routes/               # маршрути: invoices, clients, services, settings
views/                  # шаблони EJS (сторінки та друкована форма рахунку)
public/                 # CSS та JS для інтерфейсу
data/                   # база даних SQLite (створюється автоматично)
test/                   # автотести
```

## Технології

Node.js · Express · EJS · вбудований SQLite (`node:sqlite`) · bcrypt для паролів.
Без важких залежностей і без етапу збірки.
