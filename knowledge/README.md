# База знань тренажера

Тут лежить сирий матеріал, з якого пишуться лекції, тести й характери AI-клієнтів.

## Два шари — не змішувати

**Ядро** — універсальна методологія холодного дзвінка: структура входу, питання,
алгоритм відпрацювання заперечення, закриття на наступний крок. Однакове для
друкарні, упаковки, вікон і страхування. **Це продукт, який ми продаємо.**
Пишеться на основі перевірених методологій і матеріалу з усіх компаній одразу.

**Шар компанії** — те, що вводить сам клієнт через анкету в тренажері: продукт,
портрети клієнтів, переваги, свої заперечення, мета дзвінка.

Матеріал збираємо так, щоб ці шари не злиплися. Заперечення «дорого» — універсальне,
воно йде в ядро. «У нас своя друкарня в структурі» — специфічне для Дніпрографа,
воно йде в анкету компанії, а не в лекцію.

## Що де лежить

```
knowledge/
  Журнал-заперечень.xlsx     Роздати менеджерам. Два тижні. Головний інструмент
  01-план-збору.md           Що збирати, у якому порядку, скільки це коштує часу
  02-інтерв'ю.md             Сценарій розмови з найкращим менеджером
  03-спостереження.md        Як сидіти поруч і що записувати
  04-тайний-покупець.md      Дзвінки конкурентам: що слухати й фіксувати
  05-розшифровка.md          Шаблон розбору одного дзвінка
  tools/anonymize.js         Анонімізатор розшифровок (див. tools/README.md)
  записи/                    Аудіо реальних дзвінків (у git не потрапляє)
  компанії/
    дніпрограф/              Матеріал по компанії: заповнена анкета, заперечення
    смартекопак/
```

Аудіозаписи в репозиторій **не комітимо** — там персональні дані. Тримайте їх
у спільній папці компанії, а сюди кладіть тільки розшифровки без прізвищ клієнтів.

## Як розшифровки сюди потрапляють

1. РОП відбирає 20–30 дзвінків у панелі телефонії й завантажує аудіо.
2. Розпізнавання **локально** — файли не виходять із комп'ютера.
3. `node tools/anonymize.js` вичищає телефони, суми та імена й складає готові `.md`.
4. Перегляд очима за переліком підозрілих слів, який показує скрипт.
5. Тільки після цього — коміт.

Телефонія Дніпрографа (CallsApp) розшифровок у тарифі не дає, тому крок 2
обов'язковий. Інтеграція з її API поки не робиться: для двадцяти дзвінків
кнопка «завантажити» у панелі швидша за роботу з недокументованим API.
