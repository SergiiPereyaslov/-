# Інструменти

## anonymize.js — анонімізатор розшифровок

Готує розшифровки дзвінків до того, щоб їх можна було покласти в репозиторій
і використати в тренажері: вичищає персональні дані й приводить до єдиного формату.

### Запуск

```bash
node anonymize.js --in ./сирі --out ../компанії/дніпрограф --names ./імена.txt
```

| Параметр | Що це |
|---|---|
| `--in` | папка з сирими розшифровками: `.txt`, `.md`, `.srt`, `.vtt` |
| `--out` | куди складати готові `.md` |
| `--names` | файл замін імен і назв (не обов'язковий, але потрібний) |
| `--dry` | лише показати звіт, нічого не записувати |

### Файл замін

По одному рядку, `реальне = анонімне`:

```
# Клієнти
Ірина Коваленко = [Клієнт А]
Ірина = [Клієнт А]
Кав'ярня «Зерно» = [кав'ярня]

# Конкуренти
Поліграф-Сервіс = [постачальник]
```

**Беріть заміни в квадратні дужки.** Українська відмінює, а підстановка ні:
«працюємо з поточний постачальник» читається як помилка, а
«працюємо з [постачальник]» — як закреслене місце, і це правильно.

Довші варіанти застосовуються першими, тому «Ірина Коваленко» заміниться
раніше за «Ірина» — порядок рядків у файлі не має значення.

### Що прибирається автоматично

Номери телефонів у всіх поширених записах (`067 555 44 33`, `+380671234567`,
`(067) 555 44 33`, `067-555-44-33`), e-mail, суми в гривнях і валюті,
послідовності з 8+ цифр — картки, ЄДРПОУ, рахунки.

### Що скрипт НЕ вміє

**Вгадувати імена, яких немає у файлі замін.** Тому в кінці він показує всі
кириличні слова з великої літери, яких не знає, — перегляньте перелік очима.
Він навмисно з запасом: краще показати зайве, ніж пропустити ім'я.

Перевірка людиною тут не формальність — це остання ланка захисту.

### Тести

```bash
node --test knowledge/tools/test/anonymize.test.js
```

15 тестів, по одному на кожне правило очищення. Скрипт працює з персональними
даними реальних клієнтів, тому пропущений телефон — це витік, а не косметичний
баг. Тести також ловлять пастку, на якій цей скрипт уже один раз спіткнувся:
`\b` у JavaScript не знає кириличних літер, через що «12500 грн» спершу не
розпізнавалось як сума.
