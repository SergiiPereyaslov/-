# Шаблон розбору одного дзвінка

По цьому шаблону розбираються записи. З розібраних дзвінків збираються приклади
для лекцій і характери AI-персонажів.

Копіюйте цей файл під кожен розібраний дзвінок.

---

## Паспорт

- **Дата:**
- **Менеджер:**
- **Кому дзвонили:** тип клієнта, не назва — «кав'ярня на 60 місць»
- **Хто взяв трубку:**
- **Тривалість:**
- **Результат:** Так / Ні / Можливо

## Розшифровка

Дослівно, з таймкодами. Розмовні слова, паузи й «ееее» **не прибирати** — саме
вони роблять матеріал живим.

```
00:00  М: Доброго дня! Олександр, компанія…
00:07  К: Так, слухаю вас
00:09  М: …
```

## Розбір

**Що спрацювало** — конкретні фрази з таймкодами, не загальні враження.

**Де втратив** — момент, після якого розмова пішла не туди. Одна точка, не список.

**Що клієнт сказав дослівно** — заперечення, питання, відмовки. Ці рядки йдуть
прямо в тренажер.

**Що клієнт, схоже, подумав** — ваша гіпотеза. Саме з неї збирається блок
«що подумав клієнт» у розборі тренажера.

- **Поточний постачальник:**
- **Що приховував і за яких умов сказав:**
- **Чим його можна було зачепити:**
- **Після чого поклав би трубку:**
